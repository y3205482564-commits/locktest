## 项目介绍
- 框架版本: yudao-ui-admin-vben(master-vben2.0分支)
- vue3.x + typescript5.x + vite4.5 + ant-design-vue 4.x + pinia2.x 版本
- github地址: https://github.com/yudaocode/yudao-ui-admin-vben/tree/master-vben2.0
- node版本: v18.20.8
- pnpm版本: v8.15.9 (推荐pnpm,不要用npm或yarn)
